01.1 StudyStack — offline reviewer for BS IT coursework React · Supabase · PWA 2026 →

Problem

Classmates studied from screenshots and group-chat photos. Nothing was searchable, nothing survived the bus ride home with no signal.

Approach

A local-first card store in IndexedDB, synced to Supabase when a connection exists. Spaced-repetition intervals computed on the client, so the app never blocks on the network.

Outcome

Working fully offline after first load; sync conflicts resolved last-write-wins per card. Deployed on Vercel, used by my review group.

01.2 Barangay Records — resident registry & certificate requests Python · FastAPI · Postgres 2025 →

Problem

Records lived in six notebooks. Issuing a barangay clearance meant reading handwriting and re-copying details by hand — slow, and easy to get wrong.

Approach

Typed resident records with search-as-you-type, then a request workflow that fills a certificate template from stored fields and produces a printable PDF.

Outcome

Certificate issuance went from ~15 minutes to under two. Built as a school project, then rebuilt as a real deployable service with role-based access for staff.

01.3 Sari-Sari POS — a receipt printer that runs on a ₱3k tablet Python · SQLite · Bluetooth 2025 →

Problem

A neighbourhood store tracked credit ("lista") in a notebook, so balances were guessed at and lost. Existing POS apps assumed a desktop and a fast connection.

Approach

One SQLite file, a touch grid of products, and Bluetooth ESC/POS printing. Utang balances tracked per customer with a running ledger.

Outcome

Runs on a low-end Android tablet, prints paper receipts, and needs no internet. Automated backup of the database to a shared drive nightly.
